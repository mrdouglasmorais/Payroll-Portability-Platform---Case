# design-system

## Objective
Ensure visual consistency.

## Procedure
1. Read the applicable spec, ADR and existing code.
2. Identify affected invariants and failure modes.
3. Apply these rules: Semantic tokens, light/dark themes, status labels not color alone; reuse components.
4. Implement the smallest coherent change and positive/negative tests.
5. Record actual validation and unresolved limitations.

## Acceptance gate
Visual and keyboard review. Do not claim success without execution evidence.
