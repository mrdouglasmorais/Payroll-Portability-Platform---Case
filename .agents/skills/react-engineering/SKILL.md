# react-engineering

## Objective
Build typed React UI.

## Procedure
1. Read the applicable spec, ADR and existing code.
2. Identify affected invariants and failure modes.
3. Apply these rules: Use composable components, accessible controls and explicit loading/error states.
4. Implement the smallest coherent change and positive/negative tests.
5. Record actual validation and unresolved limitations.

## Acceptance gate
Component tests and typecheck. Do not claim success without execution evidence.
