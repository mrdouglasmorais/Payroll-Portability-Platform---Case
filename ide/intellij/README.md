# IntelliJ — run configurations (lab)

`.idea/` is gitignored. To import the Debug configs:

1. Create `.idea/runConfigurations/` in the repo root (IntelliJ does this after first open).
2. Copy the XML files from this folder into `.idea/runConfigurations/`.
3. Reload the project (or reopen the Run/Debug Configurations dialog).

See [docs/runbooks/load-test-intellij-debug.md](../../docs/runbooks/load-test-intellij-debug.md).
